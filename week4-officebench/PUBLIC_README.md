# 第四周独立目录

此目录只发布人工设计的图、操作引擎、测试和脱敏统计。实际模型轨迹、OfficeBench 原始/改后文件和逐次证据未上传。请先阅读[仓库首页](<../README.md>)与[阶段报告](<第四周阶段报告.md>)，并区分“本机验证通过”与“公开仓库可独立复验”。

- [问题清单](<问题清单.md>)：10 个可辩护修复候选及兼容/冲突事项。
- [证据索引](<证据索引.csv>)：21 题的本机结果汇总；其中原始来源路径仅供持有本机实验数据者核对，不是可访问的 GitHub 文件。
- [执行说明](<ENGINE_USAGE.md>)：准备合法 OfficeBench 数据及教师服务后的测试入口。

`cases.json` 的 `source` 是示例相对路径 `../OfficeBench`；实际运行时需要按本机目录设置。没有上传教师工程整包、其依赖、数据库口令和隐藏参考答案。`build_evidence_index.py` 必须有本机未公开的 `runs/`、`bridge-runs/` 与先前基线证据才会重新生成索引，不能在空仓库重算。
